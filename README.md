# FINLY

### Your money. Your rules.

Персональный финансовый помощник в Telegram.

## Возможности

- Учёт доходов и расходов
- Управление счетами и переводами
- Аналитика финансов
- Финансовые цели
- Дневной бюджет и защищённый резерв
- Редактирование операций

## Технологии

Python · FastAPI · SQLite · JavaScript · Telegram Mini Apps

## Интерфейс

Светлый минималистичный дизайн с коралловыми акцентами.

## Безопасность

Токены, базы данных и личные финансовые сведения не публикуются.
